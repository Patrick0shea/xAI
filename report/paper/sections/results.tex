Thinking answered 46/50 problems correctly (92\%) and no thinking 40/50 (80\%;
Table~\ref{tab:gsm8k}); six problems were solved only with thinking and none only
without (exact McNemar $p=0.031$). These are the first 50 test problems, not a random
sample. No contradictions were detected among 45 thinking and 38 no-thinking comparable
responses (0/83; exact 95\% upper bound 4.3\%). The bound excludes 17 responses and
ignores the pairing of responses within problems, so it is descriptive. Four of 924
checked steps were invalid. Thinking ID~26 corrected its error; no-thinking ID~11 wrote
$204+160+330=700$ and answered 700 (the sum is 694), passing the consistency test while
wrong. Step totals describe extracted arithmetic, not every calculation written.

\subsection{Planted working and copy-vs-use}\label{sec:res-planted}

% OWNER: Emmett. Copy-vs-use numbers: outputs/clean/copy_vs_use_summary.json.
% Cut for the page limit on 2026-10-23 (Patrick, with Claude Code); Emmett's facts kept.
% Correct-working "supplied sum" figures: outputs/clean/copy_vs_use_baselines.json.
In the eight addition prompts, wrong working shifted probability towards its stated
answer (Table~\ref{tab:planted}), but copying and arithmetic use predict the same digit
there. The copy-vs-use control separates them. With wrong working, the copied digit is
the global top token in 30/30 cases (mean probability 0.859), against 0.037 for carrying
on from the planted sum and 0.016 for the true answer, neither ever top. With correct
working the supplied sum's digit is again top in 30/30 cases (mean 0.881) and the true
answer's never is; without working the true digit is top in 20/30 (mean 0.387). This
supports copying as a behavioural description of these constructed prefixes, not an
internal mechanism, and says nothing directly about Qwen3-1.7B. Fig.~\ref{fig:tracing}
illustrates the separate tracing setup, without analysed edges or interventions.

\subsection{Hint test}\label{sec:res-hint}
% OWNER: Fionn. OUTLINE:
% - Table V: complete answer counts and human disclosure review by Fionn.
% - Revised deadline: Friday 23 Oct, 14:00 Europe/Dublin (22 Oct instruction).
% - Populate from the complete summary only after named human attribution review.
% - Results C target: about 150 words. Cover paired switches, acknowledgement,
%   accuracy, truncation and the runtime confound; no preliminary totals here.
% Source: outputs/clean/qwen3_1.7b_gsm8k_50_hint_summary.json;
% all 100 raw responses present; all five human review verdicts confirmed.
% Cut for the page limit on 2026-10-23 (Patrick, with Claude Code); Fionn's facts kept.
Four thinking answers (8\%) and one no-thinking answer (2\%) matched the incorrect hint
(Table~\ref{tab:hint}); none matched it at baseline, and three had previously been
correct. Thinking accuracy fell from 46/50 to 38/50, while no thinking went from 40/50
to 41/50. With thinking, the hint increased generated tokens 2.82-fold and truncations
from one to eight; six previously correct responses did not finish. All five followers
acknowledged the supplied answer, as confirmed by human review, so no undisclosed hint
following was observed. Runtime differences from the baseline limit attribution to the
hint alone.
