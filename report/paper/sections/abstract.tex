\begin{abstract}
Reasoning models write out their working before answering, and readers treat that
working as an explanation. We test whether Qwen3's final answers follow from its own
written reasoning, using a label-free formal check: we extract each arithmetic step,
re-evaluate it with exact rational arithmetic, and compare the final answer with the
answer the working reaches. On 50 paired GSM8K problems, thinking mode raised
accuracy from 80\% to 92\% (exact McNemar $p = 0.031$). In both modes, no final
answer contradicted its working in 83 comparable responses (95\% upper bound 4.3\%),
and only 4 of 924 checked steps were wrong. We argue that this shows consistency,
not faithfulness: a model can write working that matches its answer without using it.
Planted wrong working changes Qwen3-0.6B's answer, so the model is sensitive to its
written reasoning. \textbf{TBD: one sentence each on the copy-vs-use control and the
hint test, if they made the freeze.} A Z3 logic checker, validated on FOLIO
annotations, extends the approach to first-order logic.
\end{abstract}
