\subsection{Arithmetic consistency checker}\label{sec:method-arith}
% OWNER: Patrick. OUTLINE -- describe it as code/src/arithmetic_checker.py actually works:
% - Reasoning text = the thinking (thinking mode) or the response before its
%   "Final answer" line (no-thinking mode).
% - Normalisation: LaTeX (\times, \frac, \cdot), Unicode operators, word operators
%   ("times", "divided by", "is"), thousands commas and percentages; text is split
%   into clauses (lines, sentence ends, ", ") so numbers from different clauses
%   never merge.
% - Extraction: equation chains a = b = c, checked as adjacent pairs where the left
%   side contains an operator. Clauses with variables or unsupported text are
%   skipped, not counted as wrong.
% - Evaluation: EXACT RATIONAL ARITHMETIC with Python's fractions.Fraction. Every
%   number is converted to a Fraction, so 0.1 + 0.2 = 0.3 exactly. NOT SymPy.
%   A step is valid if both sides are equal, or equal after rounding to the number
%   of decimals the model wrote (e.g. 20/3 = 6.67).
% - Correction flag: a nearby "wait", "actually", "mistake", ... within 200
%   characters after an invalid step. A heuristic only; ID 26 was confirmed by hand.
% - Implied answer: thinking mode uses the last "Final answer:" or \boxed{} inside
%   the thinking; no-thinking mode uses a consistent \boxed{} in the working, else
%   the result of the last step if no other number follows it. This is compared
%   exactly with the parsed final answer. Truncated rows are not compared.
% - Contradiction = final answer differs from the implied answer, among rows
%   where both exist ("comparable responses": 45 thinking, 38 no-thinking).
% - Validation history: 53 -> 1 false positives on the pilot; regression tests for
%   each failure type. -> journal/2026-10-06.md; code/src/test_arithmetic_checker.py
% - Human audit: all 4 invalid steps + 20 seeded valid steps + hand step counts on
%   10 responses for coverage. -> outputs/clean/checker_audit_sheet.md (Conor).
%   Results go in Table I's caption or text once filled in: TBD.
