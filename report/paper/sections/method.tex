\subsection{Generation and answer parsing}\label{sec:method-gen}
% OWNER: Fionn. STARTER DRAFT (written with Claude Code, 2026-10-20): Fionn to
% check every sentence against its source, rewrite, and commit as his own.
% Sources: outputs/raw/qwen3_1.7b_gsm8k_50_completed.config.json; README.md;
% journal/2026-10-01.md; journal/2026-10-06.md; journal/2026-10-20.md;
% outputs/clean/qwen3_1.7b_gsm8k_50_completed_report.md
We ran Qwen3-1.7B~\cite{qwen3} on the first 50 GSM8K test problems~\cite{cobbe2021}
in both modes of the same model, giving 100 responses (seed 42, batch size 1). Token
limits were 8,192 with thinking and 2,048 without. Our pilot showed that a 2,048-token
limit cut off 6 of 20 thinking outputs. We count generated tokens up to the
end-of-sequence token rather than up to the batch padding, and flag truncation in both
modes.

Final answers are parsed conservatively: an explicit ``Final answer:'', a
\verb|\boxed{}| value, or a response that is just a number. The parser never takes
the last number in the working. Unresolved and truncated answers count as incorrect.
Raw outputs are never edited; every derived file is regenerated from them.

\subsection{Arithmetic consistency checker}\label{sec:method-arith}
% OWNER: Patrick (first draft 2026-10-20, written with Claude Code). Describes
% code/src/arithmetic_checker.py as it works: exact Fraction arithmetic, NOT SymPy.
% Sources: journal/2026-10-06.md; code/src/test_arithmetic_checker.py;
% outputs/clean/checker_audit_sheet.md.
The checker reads the reasoning text: the thinking in thinking mode, or the response
up to its ``Final answer'' line in no-thinking mode. It first normalises LaTeX
(\verb|\times|, \verb|\frac|, \verb|\cdot|), Unicode operators, word operators
(``times'', ``divided by'', ``is''), thousands separators and percentages, and splits
the text into clauses so numbers from different clauses never merge. It then extracts
equation chains such as $a = b = c$ and checks each adjacent pair whose left side
contains an operator. Clauses with variables or other unsupported text are skipped,
not counted as wrong.

Each side is evaluated with exact rational arithmetic (Python's
\texttt{fractions.Fraction}), so decimals introduce no floating-point error. A step is
valid if the two sides are equal, or equal after rounding to the number of decimals
the model wrote (so $20/3 = 6.67$ passes). An invalid step followed within 200
characters by words such as ``wait'' or ``actually'' is marked as possibly corrected;
this is a heuristic, which we confirmed by hand only for ID~26.

The \emph{implied answer} is the answer the working itself reaches. In thinking mode
it is the last ``Final answer'' or \verb|\boxed{}| inside the thinking. In no-thinking
mode it is a consistent \verb|\boxed{}| value in the working, or else the result of
the last step if no other number follows it. A \emph{contradiction} is a final answer
that differs from the implied answer. Responses with no implied answer, and truncated
responses, are not compared.

On a 20-problem pilot, the first version of the checker flagged 53 invalid steps, of
which only one was a real model error; each false-positive pattern now has a
regression test. A team member who did not write the checker is auditing it by hand
(all invalid steps, 20 sampled valid steps, and hand step counts for 10 responses):

\subsection{Logic checker and FOLIO validation}\label{sec:method-logic}
% OWNER: Conor. STARTER DRAFT (written with Claude Code, 2026-10-20): Conor to
% check every sentence against its source, rewrite, and commit as his own.
% Sources: README.md "FOLIO logic checker"; journal/2026-10-16.md; journal/2026-10-20.md
For first-order logic we use Z3~\cite{demoura2008}. The checker parses premises and a
conclusion written in first-order logic (quantifiers, predicates and relations,
equality, and the usual connectives) and reports whether the conclusion is entailed,
contradicted or unknown. Inconsistent premises, parse errors and solver timeouts are
reported separately from logical uncertainty, so checker failures are never counted
as model errors. Optional formal reasoning steps are checked in order, and only proved
steps can support later ones. We validate the checker on the official FOLIO
annotations~\cite{han2024folio} (Table~\ref{tab:folio}). This is a check of the
checker, not a faithfulness result: we did not check any model's logic reasoning,
because free-text reasoning would first have to be translated into first-order logic.

\subsection{Planted working and copy-vs-use}\label{sec:method-planted}
% OWNER: Emmett. STARTER DRAFT (written with Claude Code, 2026-10-20): Emmett to
% check every sentence against its source, rewrite, and commit as his own.
% Sources: journal/2026-10-07-circuit-tracing.md; journal/2026-10-15.md (decision 4)
Circuit-tracing transcoders for Qwen3-1.7B did not fit in free Colab memory, so these
tests use Qwen3-0.6B with short prompts of the form ``Question: $a+b=?$ / Working:
\dots / Final answer:''. We record the probability of the first answer digit (digits
are single tokens in Qwen), comparing a wrong working, a correct working and no
working, on 8 hand-made addition prompts.

A wrong working that the model follows could be used or simply copied. The copy-vs-use
control separates the two with prompts whose answer needs one more step after the
working. For example, $(12+7)\times 2$ with working $12+7=21$: using the working gives
42, copying it gives 21, and the true answer is 38, so the first digits differ.

To provoke unfaithfulness rather than wait for it, we add a misleading hint to
\textbf{TBD} GSM8K problems (``a maths teacher says the answer is $X$'', with $X$
wrong) and run both modes. A response is flagged when its final answer follows the
hint but its reasoning never mentions the hint, as in~\cite{turpin2023,chen2025}.

\subsection{Statistics}\label{sec:method-stats}
% OWNER: Patrick (first draft 2026-10-20, written with Claude Code).
% Sources: code/src/paper_stats.py; outputs/clean/paper_stats.json.
We compare paired correctness between modes with an exact McNemar test. Accuracy and
the invalid-step rate have Wilson 95\% intervals. Because no contradictions occurred,
we report exact Clopper--Pearson 95\% bounds for the contradiction rate. Steps within
one response are not independent, so the step-level interval is optimistic.
