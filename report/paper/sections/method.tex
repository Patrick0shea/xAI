\section{Method}\label{sec:method}

\subsection{Generation and answer parsing}\label{sec:method-gen}
% OWNER: Fionn. OUTLINE:
% - Qwen3-1.7B, first 50 GSM8K test problems, thinking on and off, same weights
%   (100 responses); seed 42, batch size 1; token limits 8,192 (thinking) and
%   2,048 (no thinking). -> outputs/raw/qwen3_1.7b_gsm8k_50_completed.config.json
% - Why 50, not 500: a larger run only tightens the estimate around zero.
%   -> journal/2026-10-15.md, decision 2
% - Token counts through EOS (not batch padding); truncation flagged in both modes.
%   -> journal/2026-10-01.md (the four pilot bugs)
% - Conservative parser: explicit "Final answer:", \boxed{}, or a lone number;
%   never the last number in the working; unresolved answers count as incorrect.
%   Bold answers ("**230**") were wrongly rejected until 2026-10-20.
%   -> README.md; journal/2026-10-06.md; journal/2026-10-20.md
% - Raw outputs are never edited; derived files are regenerated from them
%   (raw SHA-256 recorded). -> outputs/clean/qwen3_1.7b_gsm8k_50_completed_report.md
% Cut for the page limit on 2026-10-23 (Patrick, with Claude Code); Fionn's facts kept.
We generated 100 paired responses from Qwen3-1.7B on the first 50 GSM8K test problems,
enabling and disabling thinking with the same weights (seed 42, batch size one; token
budgets 8,192 and 2,048). Sampling used temperature 0.6 and top-$p$ 0.95 with thinking,
otherwise 0.7 and 0.8, with top-$k$ 20. Prompts requested working and a numeric
``Final answer''. Outputs reaching the budget without an end-of-sequence token count as
truncated. The parser accepts explicit final answers, unambiguous boxed numbers or
standalone numbers, never the last intermediate number; unresolved and truncated
answers count as incorrect. Raw generations are unchanged and hashed, and every
reported result was regenerated from them.

\subsection{Arithmetic consistency checker}\label{sec:method-arith}
% OWNER: Patrick (first draft 2026-10-20, revised 2026-10-22, written with Claude Code).
% Describes code/src/arithmetic_checker.py as it works: exact Fraction arithmetic, NOT
% SymPy. Sources: journal/2026-10-06.md; code/src/test_arithmetic_checker.py.
% Audit source: outputs/clean/checker_audit_sheet.md; confirmed by Conor, 22 October.
The checker reads the thinking or, without thinking, the response before its ``Final
answer'' line. It normalises LaTeX, Unicode and word operators, splits clauses, and
checks each adjacent pair in equation chains such as $a=b=c$ whose left side contains
an operator. Both sides are evaluated exactly with Python's
\texttt{fractions.Fraction}, allowing rounding to the decimals written. Unparseable
text, including clauses with variables, is skipped rather than marked wrong. A
response is \emph{comparable} when it is untruncated and has both a final answer and an
implied answer: the last ``Final answer'' or \verb|\boxed{}| in the thinking or,
without thinking, a consistent boxed value or the result of the last step. A
\emph{contradiction} is a comparable response whose two answers differ. An independent
manual audit confirmed all 24 of the checker's numerical verdicts on the four invalid
and 20 sampled valid steps; hand counts of ten responses found 122 calculations against
78 checked steps, with omissions in prose and unit-bearing expressions.

\subsection{Logic checker and FOLIO validation}\label{sec:method-logic}
% OWNER: Conor. Sources: code/src/{logic_checker,folio_parser}.py;
% outputs/clean/folio_validation_summary.json; journal/2026-10-16.md.
% Cut for the page limit on 2026-10-23 (Patrick, with Claude Code); Conor's facts kept.
Z3~\cite{demoura2008} evaluates supplied first-order formulas (quantified predicates,
relations, equality) over a nonempty domain, without unique-name or closed-world
assumptions. For consistent premises $P$, conclusion $C$ is entailed if $P\land\neg C$
is unsatisfiable, contradicted if $P\land C$ is unsatisfiable, and otherwise unknown;
parse errors, inconsistent premises and solver failures (500\,ms limit) are separate
outcomes. On FOLIO v0.0 validation annotations~\cite{han2024folio}, 191 of 199 parsed
problems matched their labels; five rows failed parsing and eight disagreements remain
unresolved. This validates the checker only: no Qwen3 reasoning was translated or
checked.

\subsection{Planted working and copy-vs-use}\label{sec:method-planted}

% OWNER: Emmett. Sources: outputs/clean/copy_vs_use_summary.json,
% outputs/clean/copy_vs_use_design.json, outputs/circuits/run_log.json.
% Cut for the page limit on 2026-10-23 (Patrick, with Claude Code); Emmett's facts kept.
These tests use Qwen3-0.6B only, with ``Question / Working / Final answer:'' prefixes,
scoring the first answer digit from full-vocabulary next-token probabilities without
sampling. Eight hand-picked addition prompts compare wrong, correct and absent working.
To separate copying from continued calculation, we fixed 30 addition-then-multiplication
cases (seed 42) whose first digits differ for copying the planted sum, multiplying it,
and recomputing the true answer, each under the three working conditions (90 prefixes,
original weights). We also traced one prefix with circuit tracing~\cite{ameisen2025} on
a transcoder replacement model (Fig.~\ref{fig:tracing}), but analysed no edges or
interventions, so it is an illustration, not evidence. Loading 1.7B transcoders exceeded available RAM; none of these
tests characterises Qwen3-1.7B.

\subsection{Hint test}\label{sec:method-hint}
% OWNER: Fionn. OUTLINE:
% - GSM8K problems with a misleading hint ("a maths teacher says the answer is X");
%   flag answers that follow the hint when the thinking never mentions it
%   (turpin2023, chen2025). n = 50 per mode; full human review by Fionn.
%   -> journal/2026-10-15.md decision 5; journal/2026-10-20.md
% Cut for the page limit on 2026-10-23 (Patrick, with Claude Code); Fionn's facts kept.
For the same 50 problems per mode, we append ``A maths teacher says the answer is $X$'',
with $X$ the gold answer plus one, before the unchanged instruction. Model, sampling
settings, budgets and seeds match the baseline, but the hint run used a CPU with
32-bit floats and \texttt{ATEN\_CPU\_CAPABILITY=default}, so random draws can differ.
We count answers equal to the hint, and baseline-correct answers that switch to it.
Every follower was read in full by hand: mentioning the teacher or the suggestion counts
as acknowledgement; repeating its number alone does not. This disclosure measure follows
prior hint interventions~\cite{turpin2023,chen2025} and does not establish an internal
mechanism. Truncated and unresolved answers stay in the denominator.

\subsection{Statistics}\label{sec:method-stats}
% OWNER: Patrick (first draft 2026-10-20, revised 2026-10-22, written with Claude Code).
% Sources: code/src/paper_stats.py; outputs/clean/paper_stats.json (interval_method fields).
Paired correctness uses an exact McNemar test; accuracy and invalid-step rates use
Wilson 95\% intervals; contradiction rates use exact Clopper--Pearson 95\% bounds.
